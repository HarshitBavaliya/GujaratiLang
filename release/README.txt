GujaratiLang for Windows (64-bit)
=================================

This portable package includes the GujaratiLang interpreter and a sample
program. No compiler, CMake, or Git installation is needed to run it.

Try the included sample
-----------------------

1. Extract the ZIP file.
2. In File Explorer, open the extracted folder, right-click an empty area, and
   choose "Open in Terminal" (or open PowerShell and change to this folder).
3. Run:

   .\gujarati.exe .\examples\hello.gj

Run your own program
--------------------

Pass the path to a GujaratiLang source file ending in .gj:

   .\gujarati.exe C:\path\to\your-program.gj

You can download more examples and read the language guide at:
https://github.com/HarshitBavaliya/GujaratiLang

For your security, download releases only from the official project page:
https://github.com/HarshitBavaliya/GujaratiLang/releases

The release includes checksums.txt with the SHA-256 checksum of the ZIP file.
