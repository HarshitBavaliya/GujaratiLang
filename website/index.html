A programming language in Gujarati

Code in a language close to home.

GujaratiLang is a small, open-source programming language that brings Gujarati words into code. Learn the building blocks of programming, one familiar keyword at a time.

Programming should feel welcoming. GujaratiLang is an ongoing community project exploring what code can look like when its keywords speak Gujarati. It is built step by step, with room for learners and contributors to shape what comes next.

No compiler needed

Download. Extract. Run.

Download a ready-to-run package for Windows, Linux, or macOS. No C compiler, CMake, or Git required.

  1. Choose the package for your system from the latest release.
  2. Extract the ZIP on Windows, or the .tar.gz archive on Linux/macOS.
  3. Run gujarati with the included sample or your own .gj file.
Download for Windows ↓

Also available: Linux x64, macOS Intel, and macOS Apple Silicon. See the install guide for run instructions.

Try the interactive input example for a program that reads a response.

Already built it? Start the prompt with .\gujarati.exe --repl on Windows, or ./gujarati --repl on Linux/macOS.
